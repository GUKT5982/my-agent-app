# สคริปต์อัดวิดีโอ demo

> [!info] เป้าหมายของวิดีโอนี้
> ให้คนที่ไม่เคยเห็นระบบเข้าใจใน 1 นาทีว่า "โยนใบเสนอราคาเข้าไป ได้ฟอร์มที่กรอกแล้วออกมา"
> แล้วจบด้วยสิ่งที่เราต้องการจากเขา: **ฟอร์มจริง 1 ใบ + ใบเสนอราคาจริง 5–10 ใบ**

## เตรียมก่อนอัด

- [ ] เช็คว่ามี server ตัวเดียวจริง: `netstat -ano | findstr :2024` ต้องเห็น `LISTENING` บรรทัดเดียว
- [ ] `langgraph dev --no-browser --port 2777` (พอร์ต 2024 มีปัญหา ดู [PROGRESS.md](../PROGRESS.md))
- [ ] Ollama ต้องต่อได้ ไม่งั้นการแกะฟิลด์จะ error — ทดสอบยิงหนึ่งครั้งก่อนกดอัด
- [ ] เปิดไว้ 3 แท็บ: `static/pdf-tester/`, ไฟล์ `demo_quote.pdf`, ฟอร์มผลลัพธ์
- [ ] ซูมเบราว์เซอร์ 125% เพื่อให้ตัวหนังสืออ่านออกตอนดูบนมือถือ
- [ ] ปิด notification ทุกอย่าง

## สิ่งที่ต้องไม่ทำ

- **อย่าตัดต่อให้เร็วกว่าที่มันทำงานจริง** — ถ้าแกะจริงใช้ 12 วินาที ให้เห็น 12 วินาที
  คนดูจะได้ตั้งความคาดหวังถูก ไม่งั้นพอใช้จริงแล้วรู้สึกว่าช้ากว่าที่โฆษณา
- **อย่าใช้คำว่า AI ลอยๆ** — บอกว่ามันทำอะไรได้และทำอะไรไม่ได้
- **อย่าซ่อนเคสที่พัง** — ถ้ามีเวลา ให้โชว์ไฟล์สแกนเอียงที่ระบบหมุนกลับให้เองด้วย
  ได้ใจความกว่าการโชว์แต่เคสสวยๆ

## หมายเหตุ

ทุกอย่างในสคริปต์นี้ทดสอบด้วย `demo_quote.pdf` + `demo_form.pdf` ที่สร้างเอง
**ยังไม่เคยรันกับเอกสารจริง** — ถ้าจะอัดหลังได้ไฟล์จริงมาแล้ว ให้อัดกับไฟล์จริงแทน
และแก้ตัวเลข 19 ช่องให้ตรงกับฟอร์มจริง
