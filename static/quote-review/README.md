# Quote Review & Scoreboard

`data/quotes.db` เก็บผลการแกะใบเสนอราคาทุกครั้งที่ graph รัน แต่ไม่มีอะไรอ่านมันกลับมาเลย
หน้านี้เปิดให้ตรวจทีละฟิลด์ว่าถูกหรือผิด แล้วเปลี่ยนสิ่งที่กดให้กลายเป็นสองอย่าง:

- **คะแนนรายฟิลด์** — รู้ว่า `unit_price` ผิดบ่อยกว่า `vendor_name` กี่เท่า จะได้รู้ว่าควรแก้ prompt ตรงไหนก่อน
- **ชุดเฉลย (golden set)** — ค่าที่ถูกต้องที่กรอกกำกับไว้ ใช้เป็นเกณฑ์วัดว่ารอบหน้าดีขึ้นหรือแย่ลง

## วิธีใช้

```powershell
python scripts/export_quote_records.py
```

จะได้ `data/quote_records.json` — เปิด `static/quote-review/index.html` แล้วลากไฟล์นั้นมาวาง

กดที่รายการเพื่อกางดูฟิลด์ แล้วกด ✓ (ถูก) / ✗ (ผิด) / – (ข้าม) ทีละฟิลด์
เมื่อกด ✗ จะมีช่องให้กรอกค่าที่ถูกต้อง — กรอกไว้จะกลายเป็นเฉลย ไม่กรอกก็ยังนับเป็นผิดอยู่ดี

รายการสินค้าตรวจเป็นรายคอลัมน์ (`items · qty` = "จำนวนถูกทุกแถวไหม") ไม่ใช่รายช่อง
เพราะจำนวนแถวไม่เท่ากันในแต่ละใบ

## สิ่งที่ต้องรู้

- รายการที่ **แกะไม่ได้** (มี `extraction_error` เช่น Ollama ต่อไม่ติด) ถูกแยกออกและ
  ไม่นับเข้าคะแนน — ไม่งั้นความแม่นยำจะโดนปัญหา infra ถ่วงจนอ่านไม่ได้ความ
- ผลการตรวจถูกจำไว้ใน `localStorage` ของเบราว์เซอร์นี้เท่านั้น **กดดาวน์โหลดผลการตรวจ**
  ถ้าจะย้ายเครื่องหรือเก็บเข้า repo และใช้ปุ่มนำเข้าเพื่อโหลดกลับมาทำต่อ
- คะแนนนับเฉพาะฟิลด์ที่กดตรวจแล้ว ฟิลด์ที่ข้ามไม่ถูกนับทั้งตัวตั้งและตัวหาร

## วัดผลรอบถัดไป

ไฟล์ `quote_review_verdicts.json` มีชุดเฉลยอยู่ในตัว (คีย์ `golden` — ฟิลด์ที่กดว่าถูก
ใช้ค่าที่แกะได้ตอนนั้นเป็นเฉลย ฟิลด์ที่กดว่าผิดใช้ค่าที่พิมพ์แก้) พอแก้ prompt แล้วรันใหม่
ให้ export แล้วสั่ง:

```powershell
python scripts/export_quote_records.py --output data/quote_records.json
python scripts/score_extraction.py --golden quote_review_verdicts.json --records data/quote_records.json
```

จะได้ความแม่นยำรวม + รายฟิลด์ (เรียงจากแย่สุด) และรายการที่ค่าไม่ตรงเฉลย พร้อมบอกว่า
เทียบจากใบเสนอราคากี่ใบ จับคู่ระหว่างสองรอบด้วย `quote_no`

การเทียบค่าไม่สนช่องว่างกับตัวพิมพ์เล็กใหญ่ และเทียบตัวเลขเป็นตัวเลข (`1,200.00` = `1200`)
ฟิลด์ที่กดว่าผิดแต่ไม่ได้พิมพ์ค่าที่ถูกไว้ จะถูกข้ามและรายงานแยกให้เห็น
