อ่านผลจาก scripts/validate_pdf_extraction.py แล้วจัดเป็นรายการงานเรียงตามผลกระทบ — ไฟล์ไหนพัง ไฟล์ไหนดูเหมือนผ่านแต่ไม่ได้ข้อความ และ OCR กินเวลาตรงไหน

เปิดไฟล์รายงาน

ลากไฟล์ .json (หรือ .csv ที่ได้จาก --csv) มาวางตรงนี้ หรือกดเลือกไฟล์ — ข้อมูลไม่ถูกส่งออกไปไหน ประมวลผลในเบราว์เซอร์ล้วนๆ

# ชุดตัวอย่าง 20 ไฟล์
python scripts/validate_pdf_extraction.py --limit 20 --output pdf_validation_sample.json

# คอร์ปัสเต็ม (ช้า — ปล่อยรันทิ้งไว้)
python scripts/validate_pdf_extraction.py --output docs/test-reports/full-corpus.json
